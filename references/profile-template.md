# candidate-profile.md template

Copy this skeleton when writing a new profile. Fill every field from the resume or the interview; leave a field as `unknown` rather than guessing, and ask when a form needs it. Angle brackets mark placeholders. Do not add example values.

```markdown

## Storage
- Profile folder: <absolute path>
- Tracker: <path to .xlsx, or Google Sheet URL, or both>
- Resume text: resume-text.md
- LinkedIn profile text: linkedin-profile-text.md
- Cover letter style (after first approval): cover-letter-style.md
- Profile created: <YYYY-MM-DD>. Last updated: <YYYY-MM-DD>.
- Warm-up completed: <no | yes, YYYY-MM-DD>. First external apply approved: <no | yes>.

## Identity and contact

## Work authorization

- Needs sponsorship in future: <yes | no>

## Documents

- LinkedIn saved resume filename: <exact name, or "none saved">
- Variants:
  | Variant | Local path | LinkedIn filename | Use for |
  |---|---|---|---|
- Cover letter: <"draft from profile" | path to file or template>

## Targeting
```
